## Summary

first-public is a small public test repository for the AI Delivery Platform (project s1). It contains `hello.py`, which provides the `greet()` and `shout()` greeting helpers, and `test_hello.py`, which contains pytest tests for them. CI runs the tests via the GitHub Actions `tests` workflow on every push.
